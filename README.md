# 安心伴

一个给父母和子女一起使用的中文防骗交互原型。用一条可疑消息体验从「帮我看看」到「请家人核实」的过程。

## 运行

下载仓库，使用浏览器打开 `index.html`。无需注册、安装依赖或填写密钥。也可在该目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，然后访问本机 8000 端口。

## 可以体验什么

- 粘贴消息，查看本地关键词命中的风险线索；返回修改时保留原文。
- 浏览或搜索 12 个虚构案例，按对方要求的行为和联系渠道筛选。
- 区分「分享一个防骗案例」和「我确实遇到了类似情况」。
- 在同一网页内切换模拟家人角色，填写求助、回应及查看待办。
- 切换大字模式，或播放一段预设的代接电话文字剧本。

## 数据与边界

输入留在页面内存，刷新即清空；不会上传，也不会向其他设备发送通知。关键词没有命中不代表消息可信。此版本没有接入大模型、Sherlock、电话、短信、推送服务或生产账号系统。

## 检查

安装 Node.js 后，可运行 `node tests/flow.test.cjs` 检查求助优先级、角色计数、案例搜索及文字转义。

欢迎用虚构例子提交建议。请勿提交真实手机号、验证码、聊天记录或联系人信息。
